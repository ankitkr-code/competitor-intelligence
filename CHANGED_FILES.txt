Competitor Intelligence - Phase 9 - Background jobs (Redis + BullMQ)
Split pack: Phase 9 only, from Phase 1 to Phase 9.
Apply in order 1 -> 9. Extract over your project folder,
choose "Replace the files in the destination" for all.
Everything else in your project is left as it is -
this pack contains ONLY this phase's files, nothing deleted.

After applying: install the new dependencies and start Redis, then restart both servers:
  cd backend && npm install
  redis-server   (or: start Redis however you installed it; port 6379)
  npm run dev    (backend — the scan worker runs inside it by default)
  cd ../frontend && npm run dev
For a separate worker instead: set SCAN_WORKER_IN_PROCESS=false in backend/.env
and run `npm run worker` in a third terminal.
Redis is optional — without it the app still starts and manual scans run
synchronously; scheduled scans are paused until Redis is back.
