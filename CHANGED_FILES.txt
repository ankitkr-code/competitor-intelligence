Competitor Intelligence - Phase 10 (Notion + Salesforce) - BACKEND FILES ONLY
This zip has ONLY the backend part of Phase 10 (12 files + README).
Use it together with the frontend part, which is already in the main
Phase 10 zip (competitor-intelligence-split-phase10.zip) under frontend/.
If you already extracted the main Phase 10 zip and only the frontend
showed up, extract THIS zip over your project folder too - it adds the
backend folder. Choose "Replace the files in the destination" for all,
then restart BOTH servers (npm run dev). No npm install needed.

What these files do: connect Notion and Salesforce with OAuth (tokens
encrypted with AES-256-GCM, never stored in plain text), push any
battlecard or detected change to Notion as a page or to Salesforce as
a Task. Setup keys go in backend/.env (see the README Phase 10 section).
Also in here: the Phase 9 worker race fix (no more orphaned scan-job
records stuck on 'queued').
